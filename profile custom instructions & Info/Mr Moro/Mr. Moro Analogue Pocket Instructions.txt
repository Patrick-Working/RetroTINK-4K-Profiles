All profiles work with 1080p and 720p output from the Pocket. I prefer leaving the Pocket in 1080p.
480p from the pocket has a very nasty issue on the top of the screen on my Pocket, so the profiles won't work with the pocket outputting 480p.

==============================
===GBA Authentic Cartridges===
==============================
1) Go into Analogue Button > Settings > Pocket > Systems > GBA > Video > Display Mode > Select Analogue GBA (this is also achieved by holding the "Analogue" Button and pressing left a maximum of 2 times)
2) Go into Analogue Button > Settings > Pocket > Systems > GBA > Video > Display Mode > Turn Frame Blending Off
3) Select the GBA 13x Profile in the RT4K

-For 1080p output-
Go into Analogue Button > Settings > Pocket > Systems > GBA > Video > Display Mode > Size/Position > Select Scale 6x

-For 720p Output--
Go into Analogue Button > Settings > Pocket > Systems > GBA > Video > Display Mode > Size/Position > Set Width to 960 and Height to 640

===============================
===GB/C Authentic Cartridges===
===============================
1) Go into Analogue Button > Settings > Pocket > Systems > GB (or GBC) > Video>Display Mode > Select Analogue GB (or Analogue GBC) (this is also achieved by holding the "Analogue" Button and pressing left a maximum of 4 times)
2) Go into Analogue Button > Settings > Pocket > Systems > GBA > Video > Display Mode > Turn Frame Blending Off
3) Select the GBC 15x Profile in the RT4K

-For 1080p output-
Go into Analogue Button > Settings > Pocket > Systems > GB (or GBC) > Video > Display Mode>Size/Position > Select Scale 7x

-For 720p output-
No action needed, load the profile.

~~~~~~~~~~~
~Open FPGA~
~~~~~~~~~~~
1) Go into Analogue Button > Core Settings > Display Mode > Select Normal
2) Go into Analogue Button > Core Settings > Display Mode > Mode Settings > Turn Frame Blending off
3) Go into Analogue Button > Core Settings > Display Mode > Mode Settings > Size > Select Integer
4) Unless it's addressed below, no further action is necessary. Select the appropriate core and accompanying profile and enjoy!

==============================
===Mazamars312 Neo Geo Core===
==============================
Make your way to Analogue Button > Core Settings > Turn on 320/304 H Video Output
