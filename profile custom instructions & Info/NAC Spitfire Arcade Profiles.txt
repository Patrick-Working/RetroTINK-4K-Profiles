These profiles were created using actual arcade hardware and a NAC Splitfire. All profiles use square pixel interger scaling except Tate games. All profiles are HD-15 RGBS unless otherwise stated. Drop the image folder into the root of your Retrotink 4k sd card and drop the Arcade NAC Splitfire folder into you profiles folder. These four platforms are the first of many. I will be releasing profiles for a lot of arcade hardware soon. Enjoy and please message me (BIGTIME) on the retroTINK discord with any questions or input.
